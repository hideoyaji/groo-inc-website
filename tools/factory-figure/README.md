# FACTORY コンセプトモデルの図の生成スクリプト

`/factory.html` に埋め込んである断面図 (SVG) の生成元です。**手で座標を書かないこと。**

## 使い方

```
python3 tools/factory-figure/gen.py     # 同じフォルダに out.svg が出る
```

出た `out.svg` の中身を、`factory.html` の `<div class="fac-wrap">` の中 (`<svg class="fac-svg" ...>` から `</svg>` まで) と丸ごと差し替えます。インデント (半角8スペース) も色名も class 名も、本文と一致するように生成しているので、そのまま貼れます。

`out.svg` は生成物なので、git には入れません (`.gitignore` 済み)。

## 一致確認

貼り替える前後で、本文と生成物が一致しているか確かめられます。

```
python3 - <<'PY'
page = open('factory.html', encoding='utf-8').read().split('\n')
gen  = open('tools/factory-figure/out.svg', encoding='utf-8').read().split('\n')
s = next(i for i, l in enumerate(page) if '<svg class="fac-svg"' in l)
e = next(i for i, l in enumerate(page) if l.strip() == '</svg>')
print('一致:', page[s:e+1] == gen)
PY
```

## 仕組み

斜投影です。`P(u, v, Y, z)` が、床の上の位置 (奥行き `v` は 0 が手前、1 が奥) と高さ `z` を、画面の座標に変換します。

```
X0=230, W=520, DX=175, DY=-55
P(u,v,Y,z) = (X0 + u + DX*v,  Y - 55*v - z)
床レベル (手前エッジ y): B3=756, B1=564, 1F=468, 2F=372, 3F=276, 4F=180, 屋根=84
地面 = 1F の 468
viewBox = "30 -8 1200 790"
```

各階は `slab()` (床) → `walls()` (壁) → 家具 → 人、の順で描きます。人は `person(u, v, Y, kind, rot, sc, z)` です。

## ⚠ 直すときの決まりごと

- **群衆を等間隔・同一ポーズで並べないこと。**社長の指示 = 「クラブは皆が揃ってるのが超いや。俺のイメージと違う。思い思いのダンス」。踊る型は `fac-figd1` 〜 `fac-figd5` の5種類あり、一人ずつ回転 (±14度) と大きさを変えて列を崩してあります。
- **数の細かさは追わないこと。**「投資先何社とか細かいところはどうでも良い。むしろ雰囲気が大切」。
- 図に説明的なキャプションを足さないこと。**図は図として置く。**
- ラベルは3行 (タグ / 動詞 / 用途)。動詞が長いので `viewBox` の幅を 1200 まで広げてあります。

## 各階

| 階 | 動詞 | 用途 |
|---|---|---|
| 4F 最上階 | ホールドする | 会員ラウンジ |
| 3F | 成長する | インキュベーション |
| 2F | 葛藤を超える | ワークショップ |
| 1F 地上 | 開く | オフィス・アトリエ・カフェ |
| B1 | 行動しインパクトを出す | クラブ |
| B2-B3 | 恐れを捨てる | 小劇場 (2層吹き抜け) |

地面の線は 1F にあります。**恐れを捨てるのが一番深いところにあり、ゴールでなく出発点です。**
